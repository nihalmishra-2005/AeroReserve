# AeroReserve
Airline Reservation System built using Java Spring Boot, Thymeleaf, MySQL, Spring Security, and Bootstrap. Features include user authentication, flight search, seat selection, booking management, cancellation system, admin dashboard, and responsive UI with real-time database integration.
# AeroReserve ✈️



A full-stack Airline Reservation System built using Spring Boot, Thymeleaf, MySQL, and Spring Security.



## Features

- User Registration & Login

- Flight Search

- Seat Selection

- Economy / Business / First Class Booking

- Booking Confirmation

- Booking Cancellation

- Admin Dashboard

- Dynamic Flight Management

- MySQL Database Integration



## Tech Stack

- Java 17

- Spring Boot

- Spring Security

- Thymeleaf

- MySQL

- Maven

- HTML/CSS/JS



## Database

MySQL database is used for storing:

- Users

- Flights

- Seats

- Bookings
